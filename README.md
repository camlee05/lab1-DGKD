# Lab 1 - Đánh giá & Kiểm định

## 1. Giới thiệu

Bài thực hành môn Đánh giá & Kiểm định.

Mục tiêu của bài:

- Xây dựng một chương trình có vòng lặp và lệnh rẽ nhánh.
- Chạy và kiểm tra chương trình.
- Đưa chương trình lên GitHub.
- Viết ca kiểm thử JUnit để đạt Statement Coverage.
- Viết ca kiểm thử JUnit để đạt Path Coverage.
- Sử dụng GitHub Issues để quản lý từng yêu cầu.
- Tạo commit tương ứng khi hoàn thành từng Issue.

---

## 2. Công nghệ sử dụng

- Java 17
- Maven
- JUnit 5
- Git
- GitHub
